# JRS RSS — підписка на наукові матеріали та редакційні повідомлення

## Публічна адреса

- `https://journal.kidney.pp.ua/feed.xml` — RSS 2.0.
- Посилання на RSS додані на головну, до каталогу публікацій, реєстру повідомлень і футера внутрішніх сторінок.
- На головній сторінці задано метадані `rel="alternate"` для RSS-читачів.

## Які дані потрапляють у стрічку

- Фактично **опубліковані** наукові матеріали з публічного каталогу `allPublications()`.
- Фактично **оприлюднені** виправлення, занепокоєння й відкликання з публічного RLS-фільтрованого реєстру `allPublicNotices()`.
- Кожна стаття або редакційне повідомлення має власний стабільний URL і `guid`, щоб RSS-читачі не плутали записи.
- Останні 100 елементів упорядковуються від найновіших до найстаріших. Статті з датою публікації без часу вказуються як 00:00 UTC тієї дати для синтаксису RSS; це **не** твердження про реальний час виходу.
- Немає нових робіт — RSS має лише заголовок каналу, без фіктивних матеріалів або демонстраційних записів.

## Приватність, доброчесність і межі

- RSS **не** читає приватні чернетки, документи редактора чи вміст приватного PDF-бакета.
- XML-спецсимволи в назвах та описах екрануються; RSS не інтерпретує HTML авторського тексту.
- Жодних DOI, ISSN, індексації або рецензування не додається автоматично.
- Помилки отримання публічних редакційних повідомлень не маскуються мовчазним порожнім списком: стрічка не повинна приховувати вже опубліковані повідомлення про відкликання.
- Канал не розсилає email і не зберігає адреси чи інформацію про підписників. Читач додає URL до власного RSS-читача.

## Перевірки

- `npm run test:feed` — тести XML-екранування, пустої стрічки, дат, сортування, окремих виправлень і обмеження розміру.
- `npm run build` запускає тести RSS й передпублікаційного аудиту перед Next.js.
- Для перевірки у браузері відкрийте `/feed.xml` та переконайтеся, що сервер повертає `application/rss+xml; charset=utf-8`.
